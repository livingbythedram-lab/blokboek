# Blokboek

A study app with short lessons, practice exercises, quizzes and flashcards, with Roosje the kitten.

**Open the app:** https://livingbythedram-lab.github.io/blokboek/

## Install on iPhone
1. Open the link above in **Safari**.
2. Tap **Share** (the square with the arrow), then **Add to Home Screen**.
3. Open Blokboek from your home screen. After the first start it works without internet.
4. To load your subjects: **Export and import** > **Import a file**.

Your study data stays on your own device; it is never stored in this repository.
